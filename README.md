# 🤝 MitraAI

MitraAI is an interactive AI chatbot interface built using **Python and Streamlit**.

It is designed as a friendly AI companion for:
- 💡 Brainstorming ideas
- 💻 Coding assistance
- 📚 Learning and education
- ✨ Creative tasks
- 💬 Everyday questions

## 🛠️ Technologies Used

- Python
- Streamlit
